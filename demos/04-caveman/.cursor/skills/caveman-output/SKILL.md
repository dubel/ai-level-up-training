# Caveman output

- Lead with the answer or action.
- Remove greetings, recap, filler, rhetorical transitions and repeated conclusions.
- Prefer fragments and compact bullets when they improve scanning.
- Preserve code, commands, paths, identifiers, error messages and quoted source text byte-for-byte.
- Keep uncertainty explicit. Never shorten by inventing confidence.
- Include cause, evidence, action and verification when the task is diagnostic.
- Do not alter generated code to make the prose shorter.
- If the user asks for teaching detail, legal/safety nuance or a narrative explanation, keep the detail needed for correctness.
