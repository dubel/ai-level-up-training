# AI Orientation — Cursor and agentic development

**Duration:** 6 hours, including breaks  
**Format:** short introductions and demos, with most of the time reserved for hands-on work  
**Goal:** move from using AI as a chatbot to safely delegating work to an agent in your own codebase.

## Agenda

1. **AI adoption levels** — from autocomplete to team-level agent workflows.
2. **Prompting and context engineering** — goal, context, constraints, acceptance criteria, and verification.
3. **The agent in Cursor** — planning, implementation, tests, review, and when a human takes control.
4. **Rules, skills, commands, and hooks** — where to store permanent guidance and where to store procedures.
5. **Security** — prompt injection, untrusted content, tool permissions, and approval boundaries.
6. **Cost and performance** — RTK, Caveman, Ponytail, and deliberate context management.
7. **Tools, MCP, and RAG** — when a file is enough, when to use Context7, and when to build an integration.
8. **Spec-driven development** — a fast BMAD-inspired flow: spec → implementation → tests → review.
9. **Team challenge** — each team builds one workflow it can use the next day.

## What to bring

- An up-to-date Cursor installation with Agent mode available.
- A repository or a safe subset of your codebase for exercises.
- A working local build/test command for the project.
- One real task that would normally take 30–60 minutes.
- No secrets, customer data, or production access in the exercise folder.

## End-of-day outcomes

- one useful repository rule,
- one small team skill or procedure,
- an implementation-ready specification,
- a proposed tool or MCP integration with an explicit permission scope,
- agreed guardrails and initial adoption metrics.
